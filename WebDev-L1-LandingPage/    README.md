NovaAI — AI Productivity Landing Page

A modern, responsive landing page developed as part of the Oasis Infobyte Web Development & Designing Internship — Level 1, Task 1.

📌 Project Overview

NovaAI is a fictional AI-powered productivity platform. The landing page is designed to demonstrate fundamental HTML5 and CSS3 skills through a clean, responsive, and visually polished web interface.

🚀 Features

* Sticky navigation bar
* Navigation links to different sections
* Hero section with headline, description, and call-to-action button
* Features section
* About section
* Testimonials section
* Call-to-action section
* Footer with contact and social links
* Consistent color palette and typography
* Responsive layout for desktop, tablet, and mobile devices
* Hover effects and smooth scrolling
* CSS Flexbox and Grid for responsive layouts

🛠️ Technologies Used

* HTML5
* CSS3
* Google Fonts
